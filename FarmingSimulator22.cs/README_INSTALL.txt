Farming Simulator 22 - WindowsGSM plugin

1. Copy the complete FarmingSimulator22.cs folder into WindowsGSM\plugins.
2. Reload plugins or restart WindowsGSM.
3. Add Farming Simulator 22 Dedicated Server.
4. In the install window use Set Account and sign in with a Steam account that owns Farming Simulator 22.
5. Install and start the server.
6. Open the web panel URL shown in the WindowsGSM console and finish the game server setup there.

The server needs its own Farming Simulator 22 license.

The plugin does not open ports automatically. Keep the admin web panel private and create only the game-port firewall rules you actually need.
